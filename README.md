| Icono | Tipo de Commit | Descripción |

| 🚀 | **[Feat](ca://s?q=Que_es_un_commit_feat)** | Nueva funcionalidad o característica |
| 🐞 | **[Fix](ca://s?q=Que_es_un_commit_fix)** | Corrección de errores o bugs |

| 🧪 | **[Test](ca://s?q=Que_es_un_commit_test)** | Adición o modificación de pruebas |
| ⚡ | **[Perf](ca://s?q=Que_es_un_commit_perf)** | Mejoras de rendimiento |
| 🔄 | **[CI](ca://s?q=Que_es_un_commit_ci)** | Cambios en configuración de integración continua |
